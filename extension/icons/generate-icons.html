📋 How to Use These Icons

  1. Click "Download All Icons as ZIP" or download each size individually
  2. Extract the icons to extension/icons/ directory
  3. The manifest.json is already configured to use these icons
  4. Build your extension using ./extension/build-extension.sh
  5. The icons will be included in the distribution package
