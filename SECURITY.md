# Security

## Reporting a vulnerability

Please report suspected BannerBanner vulnerabilities privately through
[GitHub's private vulnerability reporting form](https://github.com/AgentiCubed/bannerbanner/security/advisories/new).
Do not disclose vulnerabilities in public issues, discussions, or pull
requests.

Include the affected version or commit, impact, reproduction steps, and any
supporting proof of concept. The BannerBanner maintainer will acknowledge the
report, investigate it, and coordinate disclosure and remediation with the
reporter.
