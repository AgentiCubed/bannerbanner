# BannerBanner security policy

## Reporting a vulnerability

Please report suspected BannerBanner vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/AgentiCubed/bannerbanner/security/advisories/new).
Do not disclose vulnerabilities in public issues, discussions, or pull
requests.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. The BannerBanner maintainers will acknowledge the report and
coordinate remediation and disclosure through the private advisory.
